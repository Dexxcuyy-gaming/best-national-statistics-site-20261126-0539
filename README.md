**DataNusa — Indonesia in Numbers.** An original national statistics site for Indonesia: population, economy, prices, labour and provinces, each figure checked against Statistics Indonesia (BPS), the World Bank and the United Nations and cited with its source and year. Seven pages on hash routes, hand-rolled SVG charts with bar/line and year-range controls, a sortable and searchable table of the ten largest provinces, and a working CSV download of every figure. Static files only — no build step, no network requests, works on desktop and phone.

## Run it

```sh
cd app && python3 -m http.server 8080
```

Then open http://localhost:8080 in a browser.
